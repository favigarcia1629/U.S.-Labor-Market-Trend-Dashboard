# U.S.-Labor-Market-Trend-Dashboard
This project pulls and visualizes U.S. labor market data from the Bureau of Labor Statistics (BLS) API, covering unemployment rates, wage growth, and job openings by sector over 30+ years.
The dashboard tells the economic story of the American labor market — from the 2008 financial crisis to the unprecedented COVID shock and recovery. Each visualization is designed to communicate policy-relevant insights.

## What This Project Does
Automated data retrieval from BLS public API
Time series visualization of unemployment, wage growth, and JOLTS data
Sector-level breakdown of job gains and losses
Annotated charts highlighting key economic events

## Key Findings
The 2020 COVID shock created the fastest labor market collapse in U.S. history — 14.7% unemployment in two months
Wage growth above 3-4% signals inflation pressure, visible in the 2021-2023 data
Job openings data (JOLTS) is a leading indicator that predicted the tight labor market before unemployment fell

## Tools & Technologies
Python, pandas, Plotly/Seaborn, BLS public API
